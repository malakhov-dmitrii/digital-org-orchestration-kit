# Digital Org Domain OrgOps

## Source Of Truth

- Current work: Linear or `.org/tasks.yaml`.
- Specs: project `outputs/` or project docs.
- Memory: GBrain, Second Brain, Codex memory as historical context.
- Evidence: task records, artifacts, gate outputs, dry-run receipts.

## Evidence

Use whichever apply:

- spec artifact;
- schema or transition table;
- grounding check;
- dry-run task record;
- digest example;
- retrospective;
- installable skill file;
- validator or adapter proof.

## Checks

- Source of truth is clear.
- Authority is explicit.
- Stage transition is valid.
- Canonical state is not double-counted.
- Kill switch policy exists.
- Orphan detection exists.
- Digest is understandable to the user.
- Memory update is reusable, not noisy.

## Common Blockers

- unclear canonical surface;
- stale memory;
- missing Linear authority;
- skill overlap;
- weak evidence contract;
- no verifier path;
- no kill switch path.
